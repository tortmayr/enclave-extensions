# Third-party content

## `@playwright/cli` agent skill

The `scripts/update-playwright-cli.sh` script copies `skills/` without changes
from the [`@playwright/cli`](https://www.npmjs.com/package/@playwright/cli)
version recorded in `playwright-cli.version`. Do not hand-edit the directory.
