## @playwright/cli agent skill (`skills/`)

[`@playwright/cli`](https://www.npmjs.com/package/@playwright/cli) npm package
(the version pinned in `playwright-cli.version`), regenerated by
`scripts/update-playwright-cli.sh`. Do not hand-edit it.
